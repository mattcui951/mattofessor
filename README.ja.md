# Mattofessor

[English](README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · **日本語** · [한국어](README.ko.md) · [Español](README.es.md) · [Français](README.fr.md) · [Русский](README.ru.md)

Windows と macOS でローカルに動く League of Legends のアシスタントです。Porofessor の代わりに使えて、Overwolf も広告もアカウント登録もいりません。日本語、英語、簡体字中国語、繁体字中国語、韓国語、スペイン語、フランス語、ロシア語に対応しています。

> このページはインストールと使い方の説明です。開発、ビルド、リリースについては英語の [README](README.md) をご覧ください。

- **プロフィール**：自分（または任意の Riot ID）のソロ／デュオとフレックスのランク、過去のランク、タグ、よく使うチャンピオン、ロール、マスタリー、対戦履歴。どの試合も 10 人全員の詳しいデータが見られます（アイテムとゴールド、または与ダメージ、被ダメージ、軽減ダメージ、回復量）。
- **対戦中**：チャンピオン選択中は味方を、試合が始まったら全員を調べます（アリーナも対応）。各プレイヤーについて、ランクと最高ランク、サブアカウントの疑い、そのチャンピオンでの試合数・勝率・KDA・マスタリー、直近 5 試合の KDA、タグ（ワンチャン、得意チャンピオン、勝率、よく使うチャンピオンのタイプ、プレメイドなど）を表示します。メイヘムと ARAM はそのモードの試合だけで判断し、サモナーズリフトのタグ（ロール、CS、デス数）は使いません。
- **ゲーム内パネル**：`Ctrl+Shift+M` でゲーム画面の上にパネルを表示／非表示します（Porofessor の `Ctrl+X` と重ならないので、同時に使えます）。ロード画面では自動で表示され、試合が始まると隠れます。`Ctrl+Shift+N` で敵のサモナースペルのタイマーを切り替えます（スペルが使われたらクリック）。どちらのホットキーも試合中だけ有効です。
- **メタ**：サモナーズリフトのロール別ティア表（勝率、ピック率、バン率）と、メイヘムのチャンピオンとオーグメントの勝率。スキル帯ごとに見られます。
- **ビルド**：ルーンとステータスシャード、サモナースペル、スキルの上げ順、スタートアイテム、ブーツ、アイテム。サモナーズリフトはロール別、ARAM は専用のビルドです。ワンクリックでクライアントに取り込めて、チャンピオン確定時に自動で取り込むこともできます。メイヘムでは、そのチャンピオンのオーグメントのランキングも表示します。
- **メイヘムのオーグメント**：チャンピオン選択中と試合中に、そのチャンピオンで選ぶべきオーグメントと避けるべきオーグメントをレア度別に表示します。オーグメントのカードが開くと、各カードの上にそのチャンピオンでの勝率が表示され、いちばん良いカードに印が付きます。カードは Windows 標準の文字認識で、クライアントの言語か英語として読み取ります。画面は保存しません。
- **パッチノート**：直近 5 パッチの変更点を、サモナーズリフトとメイヘムに分けて表示します。内容は Riot 公式の日本語パッチノートです。
- **スコア**：全試合の全プレイヤーに 0.0〜10.0 のパフォーマンススコアと順位（1 位〜10 位）が付きます。勝利チームの最高スコアが MVP、敗北チームの最高スコアが SVP です。

## インストール

1. このリポジトリの **Releases** ページ（GitHub ページの右側）を開き、最新リリースから `Mattofessor_x.y.z_x64-setup.exe` をダウンロードします。「Download ZIP」はソースコードなので使わないでください。
2. ダウンロードしたファイルを実行します。インストーラーにコード署名がないため、「Windows によって PC が保護されました」と表示されることがあります。**詳細情報** をクリックしてから **実行** をクリックしてください。管理者権限が必要で、`C:\Program Files\Mattofessor` にインストールされ、デスクトップにショートカットが作られます。
3. League of Legends を起動してサインインすると、Mattofessor が自動で接続します。Windows と一緒に起動する設定になっています（設定でオフにできます）。
4. 任意：自分専用の無料 Riot API キーを取得すると、ランク戦の正確な勝敗数が見られます。設定 > Riot API キー (任意) > **画像付きの手順ガイド** から手順を確認できます。キーは一人ひとつ自分のものを使い、他人と共有しないでください。

Windows 10 または 11 が必要です（WebView2 がなければ自動でインストールされます）。ゲーム内パネルをゲーム画面の上に表示するには、ゲームを **ボーダーレス** か **ウィンドウ** モードにしてください。ホットキー：`Ctrl+Shift+M` パネル、`Ctrl+Shift+N` 敵スペルのタイマー（設定で変更できます）。アンインストールは Windows の設定 > アプリから。設定とキャッシュは `%APPDATA%\Mattofessor` に保存されます。

### ウイルス対策ソフトに検出された場合

ウイルス対策ソフトがインストーラーをブロックまたは隔離し、「トロイの木馬」や「情報窃取型」と表示することがあります。これは誤検出です。理由は二つあります。インストーラーにコード署名がないことと、このアプリが League クライアントのローカルのログインファイル（lockfile）と画面を読み取ることです。どちらもウイルス対策ソフトが特に注意する動作です。このリポジトリの Releases ページからだけダウンロードし、隔離されたファイルを復元して、そのファイルと `C:\Program Files\Mattofessor` を信頼リスト（除外リスト）に追加してください。

### macOS

1. 最新リリースから `Mattofessor_x.y.z_universal.dmg`（Apple Silicon と Intel 両対応）をダウンロードして開き、Mattofessor をアプリケーションにドラッグします。
2. オーグメントカードに勝率を表示するには、**システム設定 > プライバシーとセキュリティ > 画面収録とシステムオーディオ録音** で Mattofessor を許可し（設定 > オーグメント読み取りにボタンがあります）、Mattofessor を再起動してください。

macOS 13 以降が必要です（カードの勝率は macOS 14 以降）。Mattofessor はメニューバーに常駐し、設定は `~/Library/Application Support/Mattofessor`、Riot キーはキーチェーンに保存されます。

## アップデート

Mattofessor はこのリポジトリの最新リリースをバックグラウンドで確認します（GitHub アカウントは不要）。30 分ごとと、ウィンドウを開いたときや前面に戻したときに確認します。新しいバージョンがあるとバナーが出るので、**今すぐアップデート** をクリックして Windows の確認を許可すると、新しいバージョンで再起動します。試合中はアップデートしません。設定 > アップデート で自動確認をオフにしたり、**アップデートを確認** で手動確認したりできます。

## 言語

設定 > 言語 で言語を選ぶか、League クライアントの言語に合わせることができます。各言語ではその言語の文字だけを表示します。チャンピオン、アイテム、オーグメントの名前と説明、ルール、パッチノートは、その言語の Riot 公式データから取得します。まだ翻訳がない部分は表示せずに件数だけ示し、ほかの言語の文字を混ぜることはありません。

## 任意：Riot API キー

League クライアントはほかのプレイヤーのランク戦の敗北数を隠しています。Riot API キーを設定すると、全プレイヤーのランク戦の正確な勝敗数と勝率が見られ、サブアカウントの判定も正確になります。[developer.riotgames.com](https://developer.riotgames.com/) に Riot アカウントでサインインし、Register Product > Personal API Key を選んでください。個人利用限定で、申請後すぐに承認され、有効期限もありません。ダッシュボードの Development API Key は 24 時間で失効するので、アプリのガイドでは使いません。キーは Windows DPAPI で暗号化して PC に保存され、画面には表示されません。

## データの出どころ

- サインイン中の League クライアントのローカル API（LCU）と、ゲームの Live Client Data API。名前とアイコンは Riot が公開している Data Dragon から。独自のサーバーはありません。
- サモナーズリフトのティア表とビルド：OP.GG の公開エンドポイント（[opgginc/opgg-mcp](https://github.com/opgginc/opgg-mcp)）。
- メイヘムの勝率：海克斯大乱斗统计数据（[czgreat/aramhex-data](https://github.com/czgreat/aramhex-data)）、[CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/) ライセンス。中国サーバーの数百万試合のデータです。Mattofessor はこの数値を表示する場所に出典を示し、ずっと無料（非営利）です。
- メイヘムのチャンピオン調整：[League of Legends Wiki](https://wiki.leagueoflegends.com/en-us/ARAM:_Mayhem)（CC BY-SA 3.0）。オーグメントの名前と説明は Riot のゲームデータから（[CommunityDragon](https://communitydragon.org) 経由）。
- パッチノート：Riot 公式の各言語版パッチノート。
