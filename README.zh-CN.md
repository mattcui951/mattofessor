# Mattofessor

[English](README.md) · **简体中文** · [繁體中文](README.zh-TW.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [Español](README.es.md) · [Français](README.fr.md) · [Русский](README.ru.md)

一款在 Windows 本地运行的英雄联盟助手，可以替代 Porofessor：不需要 Overwolf，没有广告，也不用注册账号。支持简体中文、繁体中文、英语、日语、韩语、西班牙语、法语和俄语。

> 本页介绍怎么安装和使用。开发、构建和发布的说明见英文版 [README](README.md)。

- **个人资料**：你自己（或任何 Riot ID）的单双排和灵活排位段位、往期段位、标签、常用英雄、位置、熟练度和对局记录。每局都能看 10 名玩家的完整数据：出装和金钱，或者输出、承伤、减免和治疗。
- **当前对局**：英雄选择阶段侦察己方队友，开局后侦察全部玩家（斗魂竞技场也可以）。每名玩家显示：段位和最高段位、是否疑似小号、这个英雄的场次、胜率、KDA 和熟练度、最近 5 局的 KDA，以及各种标签（绝活哥、强势英雄、胜率、常玩的英雄类型、组排等）。海克斯大乱斗和极地大乱斗只看这类对局本身，不套用召唤师峡谷的标签（位置、补刀、死亡数）。
- **游戏内面板**：`Ctrl+Shift+M` 在游戏画面上显示或隐藏面板（特意避开 Porofessor 用的 `Ctrl+X`，两者可以同时运行）。加载界面时面板会自己弹出，对局开始后自动隐藏。`Ctrl+Shift+N` 打开或关闭敌方召唤师技能计时（对方用技能时点一下）。这两个快捷键只在对局中生效。
- **版本强势**：召唤师峡谷各位置的梯队榜（胜率、选取率、禁用率），以及海克斯大乱斗的英雄和海克斯胜率，可按段位区间筛选。
- **出装**：符文和属性碎片、召唤师技能、加点顺序、出门装、鞋子和装备，召唤师峡谷按位置分，大乱斗单独一套。一键导入客户端，也可以在锁定英雄时自动导入。海克斯大乱斗的出装页还会给这个英雄的海克斯排名。
- **海克斯大乱斗的海克斯**：英雄选择和对局中，按稀有度列出这个英雄该选和该避开的海克斯。选海克斯的卡牌弹出时，每张卡上方会显示你这个英雄配这张卡的胜率，并标出最好的一张。卡牌内容用 Windows 自带的文字识别读取，按客户端语言或英语识别，不保存任何画面。
- **版本更新**：最近 5 个版本的改动，召唤师峡谷和海克斯大乱斗分开显示。内容来自官方公告，简体中文用的是腾讯官方的中文公告。
- **评分**：每局每名玩家都有 0.0 到 10.0 的表现评分和名次（第 1 到第 10）。胜方最高分是 MVP，败方最高分是 SVP。

## 安装

1. 打开本仓库的 **Releases** 页面（GitHub 页面右侧），在最新版本里下载 `Mattofessor_x.y.z_x64-setup.exe`。不要点 "Download ZIP"，那是源代码。
2. 运行安装包。因为安装包没有代码签名，Windows 可能会提示"Windows 已保护你的电脑"：点 **更多信息**，再点 **仍要运行**。安装需要管理员权限，会装到 `C:\Program Files\Mattofessor`，并创建桌面快捷方式。
3. 打开英雄联盟并登录，Mattofessor 会自己连上客户端。它默认开机启动，可以在设置里关掉。
4. 可选：申请你自己的免费 Riot API 密钥，就能看到准确的排位胜负场。路径是 设置 > Riot API 密钥（可选）> **图文分步教程**。每个人用自己的密钥，不要把你的分享给别人。

需要 Windows 10 或 11（缺少 WebView2 时会自动安装）。游戏要用 **无边框** 或 **窗口** 模式，游戏内面板才能显示在游戏画面上。快捷键：`Ctrl+Shift+M` 面板，`Ctrl+Shift+N` 敌方技能计时，都可以在设置里改。卸载请到 Windows 设置 > 应用。设置和缓存保存在 `%APPDATA%\Mattofessor`。

### 杀毒软件报毒

火绒、360 等杀毒软件可能会拦截或隔离安装包，报成"木马"或"盗号程序"。这是误报，原因有两个：一是安装包没有代码签名，二是这个应用确实会读取英雄联盟客户端本地的登录文件（lockfile）和屏幕画面，而这些正是杀毒软件重点盯的行为。请只从本仓库的 Releases 页面下载，然后在杀毒软件里恢复被隔离的文件，并把它和 `C:\Program Files\Mattofessor` 加入信任区。

## 更新

Mattofessor 会在后台检查本仓库的最新版本（不需要 GitHub 账号）：每 30 分钟检查一次，打开窗口或切回窗口时也会检查。有新版本时会显示提示条，点 **立即更新** 并允许 Windows 的提示，它就会重启到新版本。对局中不会更新。可以在 设置 > 更新 里关掉自动检查，或者点 **检查更新** 手动检查。

## 语言

设置 > 语言 里可以选一种语言，也可以跟随英雄联盟客户端。每种语言只显示这种语言的文字：英雄、装备和海克斯的名字和说明、规则、版本公告都来自 Riot 在这种语言下的官方数据。还没有翻译的内容会隐藏起来并显示条数，不会混进其他语言的文字。

## 可选：Riot API 密钥

英雄联盟客户端会隐藏其他玩家的排位负场。填上 Riot API 密钥后，每名玩家都能看到准确的排位胜负场和胜率，小号判断也会更准。在 [developer.riotgames.com](https://developer.riotgames.com/) 用 Riot 账号登录，选择 Register Product > Personal API Key：仅限个人使用，提交后马上通过，而且不会过期。控制台首页的 Development API Key 24 小时就失效，所以应用里的教程不用它。密钥用 Windows DPAPI 加密保存在本机，界面上不会显示。

## 数据来源

- 已登录的英雄联盟客户端的本地接口（LCU）和游戏的 Live Client Data API。名字和图标来自 Riot 公开的 Data Dragon。没有我们自己的服务器。
- 召唤师峡谷的梯队榜和出装：OP.GG 的公开接口（[opgginc/opgg-mcp](https://github.com/opgginc/opgg-mcp)）。
- 海克斯大乱斗的胜率：海克斯大乱斗统计数据（[czgreat/aramhex-data](https://github.com/czgreat/aramhex-data)），采用 [CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/) 许可，数据来自国服的数百万场对局。Mattofessor 会在显示这些数据的地方注明出处，并且永久免费（非商业）。
- 海克斯大乱斗的英雄调整：[英雄联盟 Wiki](https://wiki.leagueoflegends.com/en-us/ARAM:_Mayhem)（CC BY-SA 3.0）。海克斯名字和说明来自 Riot 的游戏数据（通过 [CommunityDragon](https://communitydragon.org)）。
- 版本公告：Riot 官方各语言公告，简体中文用腾讯官方公告（lol.qq.com）。
