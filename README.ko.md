# Mattofessor

[English](README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [日本語](README.ja.md) · **한국어** · [Español](README.es.md) · [Français](README.fr.md)

Windows에서 로컬로 실행되는 리그 오브 레전드 도우미입니다. Porofessor 대신 쓸 수 있고, Overwolf도 광고도 계정 가입도 필요 없습니다. 한국어, 영어, 중국어 간체, 중국어 번체, 일본어, 스페인어, 프랑스어를 지원합니다.

> 이 페이지는 설치와 사용법을 설명합니다. 개발, 빌드, 배포에 관한 내용은 영어 [README](README.md)를 참고하세요.

- **프로필**: 내 계정(또는 아무 Riot ID)의 솔로/듀오와 자유 랭크 티어, 지난 티어, 태그, 자주 하는 챔피언, 포지션, 숙련도, 전적. 모든 게임에서 10명 전원의 자세한 기록을 볼 수 있습니다(아이템과 골드, 또는 가한 피해, 받은 피해, 경감한 피해, 회복량).
- **진행 중**: 챔피언 선택 중에는 우리 팀을, 게임이 시작되면 모든 플레이어를 살펴봅니다(아레나 포함). 플레이어마다 티어와 최고 티어, 부계정 의심 여부, 해당 챔피언의 게임 수·승률·KDA·숙련도, 최근 5게임의 KDA, 태그(장인, 주력 챔피언, 승률, 자주 하는 챔피언 유형, 듀오 등)를 보여 줍니다. 아수라장과 무작위 총력전은 해당 모드의 게임만으로 판단하고, 소환사의 협곡 태그(포지션, CS, 데스)는 쓰지 않습니다.
- **게임 내 패널**: `Ctrl+Shift+M`으로 게임 화면 위에 패널을 표시하거나 숨깁니다(Porofessor의 `Ctrl+X`와 겹치지 않아 함께 쓸 수 있습니다). 로딩 화면에서는 저절로 나타나고 게임이 시작되면 숨겨집니다. `Ctrl+Shift+N`은 상대 소환사 주문 타이머를 켜고 끕니다(주문을 쓰면 클릭). 두 단축키 모두 게임 중에만 동작합니다.
- **메타**: 소환사의 협곡 포지션별 티어표(승률, 픽률, 밴률)와 아수라장의 챔피언 및 증강 승률. 실력 구간별로 볼 수 있습니다.
- **빌드**: 룬과 능력치 파편, 소환사 주문, 스킬 순서, 시작 아이템, 신발, 아이템. 소환사의 협곡은 포지션별로, 무작위 총력전은 따로 있습니다. 클릭 한 번으로 클라이언트에 가져오고, 챔피언을 확정할 때 자동으로 가져올 수도 있습니다. 아수라장에서는 빌드 페이지에 그 챔피언의 증강 순위도 나옵니다.
- **아수라장 증강**: 챔피언 선택 중과 게임 중에 그 챔피언으로 고를 증강과 피할 증강을 등급별로 보여 줍니다. 증강 카드가 열리면 카드마다 위쪽에 내 챔피언의 해당 카드 승률이 뜨고, 가장 좋은 카드에 표시가 붙습니다. 카드는 Windows 기본 문자 인식으로 클라이언트 언어 또는 영어로 읽으며, 화면은 저장하지 않습니다.
- **패치 노트**: 최근 5개 패치의 변경 사항을 소환사의 협곡과 아수라장으로 나눠 보여 줍니다. 내용은 Riot 공식 한국어 패치 노트입니다.
- **점수**: 모든 게임의 모든 플레이어가 0.0~10.0의 성과 점수와 순위(1위~10위)를 받습니다. 이긴 팀 최고 점수가 MVP, 진 팀 최고 점수가 SVP입니다.

## 설치

1. 이 저장소의 **Releases** 페이지(GitHub 페이지 오른쪽)를 열고 최신 릴리스에서 `Mattofessor_x.y.z_x64-setup.exe`를 내려받으세요. "Download ZIP"은 소스 코드이므로 쓰지 마세요.
2. 내려받은 파일을 실행합니다. 설치 파일에 코드 서명이 없어서 "Windows의 PC 보호" 창이 뜰 수 있습니다. **추가 정보**를 누른 뒤 **실행**을 누르세요. 관리자 권한이 필요하고, `C:\Program Files\Mattofessor`에 설치되며 바탕 화면에 바로 가기가 생깁니다.
3. 리그 오브 레전드를 실행하고 로그인하면 Mattofessor가 알아서 연결됩니다. Windows와 함께 시작하도록 설정되어 있습니다(설정에서 끌 수 있습니다).
4. 선택 사항: 무료 Riot API 키를 직접 발급받으면 랭크 게임의 정확한 승패 수를 볼 수 있습니다. 설정 > Riot API 키 (선택) > **그림으로 보는 단계별 안내**를 따라 하세요. 키는 각자 자기 것을 쓰고, 다른 사람과 공유하지 마세요.

Windows 10 또는 11이 필요합니다(WebView2가 없으면 자동으로 설치됩니다). 게임 내 패널이 게임 화면 위에 나오려면 게임을 **테두리 없음** 또는 **창 모드**로 실행해야 합니다. 단축키: `Ctrl+Shift+M` 패널, `Ctrl+Shift+N` 상대 주문 타이머(설정에서 바꿀 수 있습니다). 제거는 Windows 설정 > 앱에서 합니다. 설정과 캐시는 `%APPDATA%\Mattofessor`에 저장됩니다.

### 백신 프로그램이 막을 때

백신 프로그램이 설치 파일을 차단하거나 격리하면서 "트로이 목마"나 "정보 탈취"로 표시할 수 있습니다. 이것은 오진입니다. 이유는 두 가지입니다. 설치 파일에 코드 서명이 없고, 이 앱이 리그 클라이언트의 로컬 로그인 파일(lockfile)과 화면을 읽기 때문입니다. 둘 다 백신 프로그램이 특히 주의해서 보는 동작입니다. 이 저장소의 Releases 페이지에서만 내려받고, 격리된 파일을 복원한 뒤 그 파일과 `C:\Program Files\Mattofessor`를 신뢰 목록(예외 목록)에 추가하세요.

## 업데이트

Mattofessor는 이 저장소의 최신 릴리스를 백그라운드에서 확인합니다(GitHub 계정 필요 없음). 30분마다, 그리고 창을 열거나 다시 앞으로 가져올 때 확인합니다. 새 버전이 나오면 배너가 뜹니다. **지금 업데이트**를 누르고 Windows 확인 창을 허용하면 새 버전으로 다시 시작합니다. 게임 중에는 업데이트하지 않습니다. 설정 > 업데이트에서 자동 확인을 끄거나 **업데이트 확인**으로 직접 확인할 수 있습니다.

## 언어

설정 > 언어에서 언어를 고르거나 리그 클라이언트 언어를 따르게 할 수 있습니다. 각 언어에서는 그 언어의 글만 보여 줍니다. 챔피언, 아이템, 증강의 이름과 설명, 규칙, 패치 노트는 그 언어의 Riot 공식 데이터에서 가져옵니다. 아직 번역이 없는 내용은 숨기고 개수만 보여 주며, 다른 언어의 글을 섞지 않습니다.

## 선택 사항: Riot API 키

리그 클라이언트는 다른 플레이어의 랭크 패배 수를 숨깁니다. Riot API 키를 넣으면 모든 플레이어의 정확한 랭크 승패 수와 승률을 볼 수 있고, 부계정 판단도 더 정확해집니다. [developer.riotgames.com](https://developer.riotgames.com/)에 Riot 계정으로 로그인한 뒤 Register Product > Personal API Key를 고르세요. 개인용으로만 쓸 수 있고, 신청하면 바로 승인되며 만료되지 않습니다. 대시보드의 Development API Key는 24시간 뒤 만료되므로 앱 안내에서는 쓰지 않습니다. 키는 Windows DPAPI로 암호화해 PC에 저장되며 화면에는 표시되지 않습니다.

## 데이터 출처

- 로그인한 리그 클라이언트의 로컬 API(LCU)와 게임의 Live Client Data API. 이름과 아이콘은 Riot이 공개한 Data Dragon에서 가져옵니다. 자체 서버는 없습니다.
- 소환사의 협곡 티어표와 빌드: OP.GG 공개 엔드포인트([opgginc/opgg-mcp](https://github.com/opgginc/opgg-mcp)).
- 아수라장 승률: 海克斯大乱斗统计数据([czgreat/aramhex-data](https://github.com/czgreat/aramhex-data)), [CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/) 라이선스. 중국 서버 수백만 게임의 데이터입니다. Mattofessor는 이 수치가 나오는 곳마다 출처를 밝히며, 계속 무료(비상업)입니다.
- 아수라장 챔피언 조정: [League of Legends Wiki](https://wiki.leagueoflegends.com/en-us/ARAM:_Mayhem)(CC BY-SA 3.0). 증강 이름과 설명은 Riot 게임 데이터에서 가져옵니다([CommunityDragon](https://communitydragon.org) 경유).
- 패치 노트: Riot 공식 언어별 패치 노트.
